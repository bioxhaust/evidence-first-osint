# Проверка банка интерактивного тренажёра

Дата: 2026-11-03. Область: docs/assets/trainer/lessons.js. Банк подготовлен отдельно от интерфейса тренажёра и не подтверждает сам по себе работоспособность браузерных переходов, хранения прогресса или публикации.

## Готовый состав

ESM экспортирует units: 20 блоков по 3 упражнения, всего **60**. Порядок начинается с profiles и github-tools, затем следует 18 тем основного курса. В банке **35** заданий с одним ответом, **18** с несколькими, **7** с числовым вводом. На каждый блок указано 6–8 минут; это редакторская оценка микроупражнений, не замена длительности полноценных уроков и лабораторных.

Каждый блок содержит два прикладных вводных абзаца, ссылки на урок и лабораторную. У каждого задания есть конкретные свидетельства, вопрос, правильный ответ, подсказка, объяснение и ссылка на источник. ID вариантов — стабильные строки "1", "2" и далее; тип number содержит пустой options и correct строкой.

Первые шесть заданий обучают точным самоссылкам, статусу кандидата, тайм-аутам, запуску настоящего Sherlock через локальный launcher, разбору Soft404 и различию проверенного маркера отсутствия и незавершённого запроса.

## Что проверено запуском

Среда: macOS; Node **v26.7.0**, Python **3.15.2**.

1. Модуль импортирован Node через ESM. Проверены ровно 20 блоков, 60 уникальных exercise ID и заданный порядок unit ID.
2. Программная проверка схемы: диапазон минут, по три задания, наличие briefing/evidence/hint/explanation/source, правильные ID ответов, один ответ у single, минимум один неверный вариант у multi, числовые строки у number. Ошибок не обнаружено.
3. Из payments.csv повторён фильтр по C-17, settled и границе 18 мая: **5 000 000 TST**.
4. Из payments-dirty.csv повторён расчёт с удалением точного дубликата из счётчика, карантином unknown и фильтрацией: **5 000 000 TST известных пригодных сумм**. Неизвестная строка не заменяется нулём.
5. По timeline.csv вычислен интервал публикаций B01/P01: **70 минут**.
6. По media/frames.csv вычислен интервал позиций первого и последнего кадра: **4 секунды**.
7. Реально запущена команда python3 tools/profile_candidates.py docs/assets/profiles/scanner-results.json docs/assets/profiles/profiles.json. Результат: 6 строк, 5 уникальных кандидатов, 2 corroborated, 1 candidate, 2 unknown. Этот результат проверяет исходный профильный корпус. В обновлённом блоке github-tools вместо счётчика кандидатов используется реальный Sherlock Soft404.

## Редакторская сверка

- R02 не является побайтовой копией R01: хост записан в другом регистре и добавлен #about. В упражнении это дубль страницы **после заданной нормализации URL**. Оригинальные строки сохраняются в журнале.
- Corroborated означает подтверждённую условием заявленную связь профилей с LEARNER-A; гражданская личность не устанавливается.
- Совпавшее имя без самоссылки остаётся кандидатом. Тайм-аут и not_found с непроверенным маркером не являются доказательством отсутствия.
- Команда справки sherlock --help взята из официального README Sherlock, сверенного коллегой: [фиксированная версия README](https://github.com/sherlock-project/sherlock/blob/c588d7c8b476df9f9c84912a05d1430fb8cdcdae/README.md). Блок github-tools обновлён по фактическому локальному запуску коллеги, сохранённому в docs/assets/profiles/sherlock-run.json: Sherlock 0.16.2, Python 3.14.6, macOS arm64. Проверены содержание сохранённого вывода и правила в sherlock-local-sites.json; живой поиск по платформам не заявляется. Выдуманных флагов в банке нет.
- Кандидат A выбирается по конфигурации ориентиров; числовые координаты карты остаются локальными. Расстояние A=(200,300) — B=(700,300) равно 500 м в условной системе.
- Время EXIF без пояса не переводится точно в UTC. Архивная дата не подменяет время создания.
- Общий IP или адрес не доказывает общего владельца; репосты не являются независимыми свидетельствами.
- Все цели и свидетельства синтетические; задания не требуют сетевых запросов к людям или учебным .example URL.
- Внешний API-сценарий HTTP 429 прямо помечен дополнительным и условным; это не результат фактически выполненного запроса.

## Проверка ссылок по готовой сборке

Повторная независимая проверка: **2026-11-03, 03:43 UTC**, Node.js 26.7.0, macOS arm64. Машиночитаемый результат с каждой целью и контрольными суммами: [qa-trainer-links.json](evidence/qa-trainer-links.json).

Проверены **100 ссылок**: 20 переходов к урокам, 20 к лабораторным и 60 к источникам. Они ведут на **66 уникальных целей**, все существуют в `site/`; ошибок нет. Ссылки банка менять не потребовалось.

URL вычислялись стандартным `URL` относительно `https://bioxhaust.github.io/evidence-first-osint/trainer/`, взятого из `site_url` в `mkdocs.yml`. Проверены сохранение префикса `/evidence-first-osint/`, отсутствие выхода за корень сайта и такое же разрешение относительных путей при размещении сайта в корне домена. Для каталогов проверялся итоговый `index.html`. Markdown-индексы источников правильно ведут на `assets/case/` и `assets/profiles/`: MkDocs не переписывает строки ссылок внутри JavaScript.

Для **42 Markdown-страниц**, на которые ведёт банк, найдены исходники; время файла сборки не предшествует времени исходника. Для **26 копируемых файлов**, включая банк, используемые сырые данные и весь профильный JSON-корпус, подтверждено побайтовое совпадение `docs/` и `site/`, сохранены SHA-256.

Отдельно проверены наличие и заголовки восьми страниц: уроки 19/20, лабораторные 19/20, их решения, описание профильного корпуса и страница лицензий. Адреса `.example` в тексте заданий — синтетические свидетельства, а не переходы интерфейса; сетевые запросы к ним не выполнялись.

## Включение новых материалов, лицензии и даты

Уроки и лабораторные 19/20 включены в готовую сборку, а стартовые темы и профильный корпус присутствуют в навигации `mkdocs.yml`. Все пять JSON-файлов профильного корпуса доступны в сборке; Sherlock отдельно устанавливается по лабораторной и не переупакован в курс.

`LICENSE` прямо разделяет текст и свидетельства `lessons.js` (CC BY 4.0) и исполняемую структуру/логику (MIT). Общие лицензии покрывают новые оригинальные уроки, решения и данные; описание профильного корпуса дополнительно указывает происхождение и права. В репозитории присутствуют `LICENSE-CODE`, `LICENSE-CONTENT` и `THIRD_PARTY_NOTICES.md`; публичная страница лицензий с переходами к полным текстам включена в сборку.

Новые уроки указывают дату проверки **2026-11-03**. Описание Sherlock совпадает с сохранённым фактическим локальным запуском этой даты: версия 0.16.2, Python 3.14.6, macOS arm64. Датированные сведения о Sherlock, Maigret и ExifTool сверены с [исследованием инструментов](profile-tools-review.md); в этом проходе внешние API повторно не запрашивались. Эти версии описывают состояние на дату исследования, не обещают постоянную актуальность.

## Границы проверки

Файловая проверка подтверждает разрешение URL и включение целей в локальную сборку, но не доступность опубликованного сервера или фактический переход браузера. Проверки интерфейса и состояния описаны отдельно в [trainer-ui-review.md](trainer-ui-review.md); живой OAuth и реальная синхронизация этими проверками не подтверждаются.

Интерфейс, мобильная доступность, сохранение прогресса, обработка числового ввода и общий выпуск проверяются владельцем реализации отдельно. Банк сам по себе не является подтверждением полного прохождения лабораторных или профессиональной квалификации.
