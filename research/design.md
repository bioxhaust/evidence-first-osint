# Design decision

The ui-ux-pro-max guidance was consulted on 2026-11-03. Two searches returned a portfolio grid and a child-oriented learning UI; neither was a verified fit for an adult investigative course. We use general documentation UI guidance instead: MkDocs Material navigation and search, restrained editorial typography, visible keyboard focus, readable line lengths and reduced motion.

Original identity: a small bracket around an evidence dot, navy ink, warm paper, dark teal actions. No decorative stock photography, external fonts, testimonials or invented metrics. Home page shows actual lesson, lab and checklist links. An inline challenge works without JavaScript through HTML details/summary. System fonts include Cyrillic; all essential navigation uses words. Verify desktop and 375 px viewport; record the actual test environment separately.
