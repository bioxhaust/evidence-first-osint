# Практические GitHub-инструменты для профилей и собственного следа

Дата исследования и запусков: **2026-11-03**. Цель — выбрать настоящий инструмент для основного учебного маршрута, проверить его на контролируемых страницах и показать границы автоматического результата. Звёзды, охват и популярность не измерялись. Дата push характеризует изменение репозитория, но не является независимой оценкой качества.

## Проверенные первичные источники

### Sherlock

Репозиторий: [sherlock-project/sherlock](https://github.com/sherlock-project/sherlock). Прочитаны официальный [README на commit c588d7c](https://github.com/sherlock-project/sherlock/blob/c588d7c8b476df9f9c84912a05d1430fb8cdcdae/README.md), [pyproject.toml](https://github.com/sherlock-project/sherlock/blob/c588d7c8b476df9f9c84912a05d1430fb8cdcdae/pyproject.toml), исходники [CLI 0.16.2](https://github.com/sherlock-project/sherlock/blob/v0.16.2/sherlock_project/sherlock.py) и [загрузчика сайтов](https://github.com/sherlock-project/sherlock/blob/v0.16.2/sherlock_project/sites.py).

GitHub API на дату просмотра: репозиторий не архивирован, `pushed_at=2026-11-02T05:14:33Z`; последний опубликованный release — [v0.16.2](https://github.com/sherlock-project/sherlock/releases/tag/v0.16.2), `published_at=2026-09-08T20:54:15Z`. README и pyproject указывают MIT. Python — `^3.9`; среди зависимостей requests, requests-futures, pandas, openpyxl, PySocks и stem. Классификатор версии Python не равен фактическому тесту на ней.

Функция — обнаружение username по правилам сайтов. В исходнике `status_code` может объявить любой ответ 2xx занятым профилем; `message` проверяет наличие заданного текста ошибки; результат зависит от актуальности правил. README документирует `sherlock --help`, `--json` и ограничение по сайтам. Для учебного стенда выбран этот проект: базу из четырёх собственных страниц можно передать локальным JSON и проверить известные исходы.

Существенная находка по исходнику: `--local` выбирает встроенную базу настоящих сайтов и **не** отключает сеть. CLI до поиска делает запрос последнего релиза; загрузчик может запросить удалённый список исключений. Поэтому для упражнения используется прозрачный launcher установленного CLI с фиксированным custom JSON, Requests-guard и `--ignore-exclusions` только для четырёх собственных правил. Guard проверяет каждый `Session.send`, включая перенаправления, и убирает прокси из окружения для разрешённых запросов. Он не является системной песочницей или встроенной возможностью Sherlock.

PDF-экспорт имеет отдельные дополнительные зависимости, которые могут требовать системных библиотек.

Проект объединяет поиск username, извлечение дополнительных публичных атрибутов, отчёты и рекурсивные сценарии. README описывает автоматическое обновление базы и дополнительные режимы. Установка Maigret, живой поиск и качество его платформенных правил **не проверялись запуском**. Числа сайтов и рекламные обещания README не превращены в наши подтверждённые показатели покрытия.

## Фактически выполненный эксперимент Sherlock

Установлен официальный пакет `sherlock-project==0.16.2` в отдельную среду Python **3.14.6**, macOS arm64. Команда `sherlock --help` завершилась с кодом 0 и показала ожидаемые аргументы. Перед этим создание среды установленным Python 3.12 не удалось на ensurepip; системную установку не изменяли, рабочую проверку выполнили отдельным доступным Python 3.14. Это не заявление о несовместимости Sherlock с Python 3.12.

Использованы собственные файлы:

- [profile_fixture_server.py](../tools/profile_fixture_server.py): сервер только на 127.0.0.1:54369, четыре заранее заданных ответа без внешних ресурсов.
- [sherlock-local-sites.json](../docs/assets/profiles/sherlock-local-sites.json): настоящая поддерживаемая база правил Sherlock.
- [run_sherlock_local.py](../tools/run_sherlock_local.py): запускает установленный upstream CLI, передаёт фиксированные аргументы и ограничивает Requests локальным адресом.
- [sherlock-run.json](../docs/assets/profiles/sherlock-run.json): сохранённые дата, версия, среда, код завершения и выдержка фактического stdout. Рекламный footer upstream опущен с явной пометкой.

Результат: `Present` и `Soft404` получили плюс; `Missing` — Not Found; `Slow` — Timeout Error. У Soft404 профиля нет: сервер намеренно возвращает общую страницу с кодом 200. У Missing проверен собственный маркер PROFILE NOT FOUND. Slow задерживает ответ на 1 секунду при тайм-ауте CLI 0,25 секунды. В журнале guard **4 локальных запроса и 1 заблокированная внешняя попытка обновления**. Проверяемый итог — один правильный положительный ответ, один ложный, одно распознанное отсутствие внутри стенда и одна неопределённость. Реальные аккаунты не запрашивались.

Виртуальная среда не считается средством запрета сетевого доступа. Локальный guard относится только к проверенному пути Requests и этой закреплённой версии. Установка пакетов обращалась к PyPI; запрет внешних запросов относится к самому учебному поиску, а не установке зависимостей.

## Офлайн-сопоставление и регрессионные проверки

Отдельный [profile_candidates.py](../tools/profile_candidates.py) читает синтетические profiles.json и TrainingScanner JSON. Он не выдаётся за Sherlock и не импортирует его вывод. Реальный запуск дал 6 строк, 5 уникальных карточек, 2 corroborated, 1 candidate, 2 unknown; SHA-256 входов и все исходные строки сохранены в [result-example.json](../docs/assets/profiles/result-example.json).

В [tests/test_profiles.py](../tests/test_profiles.py) выполнены **8 тестов**: итог и сохранение входов; отсутствие слияния по нику без самоссылок; конфликт статусов; отказ от настоящих доменов/неверной схемы; сохранение регистра и символов пути; конфликты ID; локальная конфигурация Sherlock; различие HTTP-статуса и наличия профиля. Офлайн-анализ проверен с блокированным socket в тесте. Тесты используют стандартную библиотеку и не требуют установки Sherlock в обычной CI-среде; реальный CLI отдельно проверен описанным запуском.

## Ограничения и правовая область

Проверены только три конкретных проекта и контролируемый локальный опыт. Не заявляются полное покрытие сайтов, точность идентификации людей, анонимность или совместимость непроверенных ОС. Самоссылки подтверждают заявленные связи в условии синтетического набора; паспортная личность, текущий оператор и общность реальных владельцев ими не удостоверяются. Собственная MIT-лицензия инструмента не заменяет условия источника и основание обработки данных.

Для собственного следа дополнительно прочитаны официальные [GitHub Docs о публичном профиле](https://docs.github.com/en/account-and-profile/concepts/personal-profile), [Google Refresh outdated content](https://support.google.com/websearch/answer/6349986) и [Python venv](https://docs.python.org/3/library/venv.html), HTTP 200 на дату просмотра. Страница Google различает уже удалённый контент и сохраняющийся поисковый результат; полного удаления всех копий курс не обещает. Применимость права зависит от юрисдикции и задачи; её разбор остаётся в отдельном уроке этики.
