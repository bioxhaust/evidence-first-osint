# Учебный набор: публичные профили и свой цифровой след

**SYNTHETIC / УЧЕБНЫЙ МАТЕРИАЛ.** LEARNER-A, usernames, описания и страницы созданы авторами курса. Они не относятся к реальному человеку. Адреса `.example` — обозначения для чтения; обращаться к ним по сети не нужно. Локальный HTTP-стенд использует только `127.0.0.1:54369` на вашем компьютере.

В условии LEARNER-A управляет стартовой страницей `home.example/learner-a`. Она ссылается на два собственных профиля. Задача — проверить, какие находки относятся к этому заявленному набору и что остаётся неизвестным, затем составить план проверки **своих** публичных настроек.

## Файлы для ручного анализа

- [profiles.json](profiles.json): стартовая страница E-HUB и пять карточек PR01–PR05; тексты, самоссылки, источник и время фиксации.
- [scanner-results.json](scanner-results.json): шесть вымышленных строк TrainingScanner, включая дубль и ошибки. Это **не** экспорт Sherlock или Maigret.
- [result-example.json](result-example.json): фактический результат локального `tools/profile_candidates.py` на двух предыдущих файлах. В нём сохранены все шесть строк и контрольные суммы входов.

Схема: `schema_version=1`, `synthetic=true`. Username — текстовое имя аккаунта; `profile_id` — ID учебной карточки; `result_id` — ID отдельного наблюдения. Дубликат URL не удаляет наблюдение из журнала.

PR01 и PR02 перечислены на известной стартовой странице: это подтверждает заявленную связь профилей в учебном корпусе, а не юридическую личность. PR03 — совпавший ник без подтверждающей самоссылки. PR04 — тайм-аут. PR05 — результат непроверенного правила «не найдено» на общей странице входа. Последние два случая сохраняют неопределённость.

## Настоящий Sherlock на локальном стенде

- [sherlock-local-sites.json](sherlock-local-sites.json): оригинальная тестовая база в поддерживаемом Sherlock формате; четыре локальных маршрута.
- [sherlock-run.json](sherlock-run.json): выдержка **фактического** запуска Sherlock 0.16.2, дата, среда и счётчики guard. Рекламный footer upstream не включён в выдержку.
- `tools/profile_fixture_server.py` возвращает учебные HTTP-ответы, включая ложный HTTP 200 и задержку.
- `tools/run_sherlock_local.py` вызывает установленный CLI Sherlock с этой базой. Учебный guard блокирует Requests-запросы за пределы локального адреса, включая автоматическую проверку обновления. Это не системная песочница и не функция самого Sherlock.

Команды и объяснение результата находятся в [лабораторной инструментов](../../practice/labs/20.md). Стенд и его ответы — синтетические; программа Sherlock и полученный результат запуска — настоящие. Один положительный ответ программы намеренно ошибочен, чтобы можно было проверить её эвристику на известной истине.
