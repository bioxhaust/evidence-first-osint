В этой учебной модели платформы:

1. ID вида `FN-число` закреплён за техническим аккаунтом и не меняется при смене username.
2. Освобождённый username может позднее занять другой аккаунт.
3. Публичный ID не является идентификатором физического лица. Передача доступа или смена оператора не отражается автоматически в ID.
4. Отображаемые имена и описания не уникальны.

Эта справка описывает только вымышленную FieldNotes. Не переносите правило неизменности ID на настоящую платформу без её документации.
