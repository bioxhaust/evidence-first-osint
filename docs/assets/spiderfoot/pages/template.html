УЧЕБНЫЙ МАТЕРИАЛ · SYNTHETIC · Описание шаблона

Шаблон SYN-TPL-2 распространяется среди учебных проектов. В комментариях осталась демонстрационная строка, похожая на идентификатор системы аналитики. Рабочий скрипт аналитики не включён.

Совпавшая строка в двух страницах может происходить из общего шаблона. Баннер Server также задаётся этим учебным сервером для всех страниц. Эти два признака не устанавливают владельца двух проектов.
