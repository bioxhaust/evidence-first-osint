# Программа: начните с находки

[Первое дело · 10–15 минут](../practice/investigations/01.md){ .md-button .md-button--primary }

Рекомендуемый вход — [три практических расследования](../practice/fieldwork.md): найти профиль, проверить биографию, разобраться в авторстве. Между делами — реальные запуски Sherlock, Maigret, ExifTool и FFmpeg. Теория ниже открывается по необходимости; затем её можно пройти полностью.

## Порядок углублённого курса

1. **[Публичные профили и свой цифровой след](19-public-profiles.md)** — самоссылки, кандидаты, неизвестное и действия в собственных настройках.
2. **[GitHub-инструменты](20-github-tools.md)** — установка, справка и настоящий Sherlock на синтетических localhost-страницах; HTTP 200 может оказаться ложным срабатыванием.
3. **Уроки 01–05:** вопрос, этика, поиск, источники, сохранение → [проект 01](../practice/projects/01.md).
4. **Уроки 06–10:** изображения, видео, место, время, карты → [проект 02](../practice/projects/02.md).
5. **Уроки 11–15:** компании, инфраструктура, публичные посты, связи, данные → [проект 03](../practice/projects/03.md).
6. **Урок 16 по желанию, затем 17–18:** программирование, проверка дезинформации/ИИ и отчёт → [итоговый кейс](../practice/capstone.md).

Числа 19 и 20 — стабильные ID новых страниц, а не требование пройти сначала восемнадцать тем. [Карта с результатами каждого модуля](../resources/course-map.md) уже расположена в учебном порядке.

## Содержание и время

**20 модулей и 20 лабораторных**, из них 19 обязательных; только модуль 16 о Python/API дополнительный. Каждый урок содержит метод, разобранный пример, самостоятельную работу, критерии, ограничения, объяснённые ответы и источники.

Лабораторные включены во время уроков. С тремя проектами и итоговым кейсом обязательный путь занимает номинально **27 ч 45 мин**; планируйте **28–36 часов** на прохождение и исправления. Короткий тренажёр — отдельные **20 блоков и 60 заданий**, примерно **2–3 часа**. Оба пути вместе — **30–39 часов**. Это оценки, не измеренные результаты обучения.

Для чтения и ручных заданий достаточно браузера и заметок. Обязательная лабораторная инструментов требует установки Python, пакета Sherlock и выполнения команд; писать программу не нужно. Модуль 16 учит собственно программированию. Сохранённый лог не заменяет выполнение технического задания.
