# Программа курса

Начните с [урока 01](01-question.md). Каждый модуль содержит метод, разобранный пример, самостоятельную работу, критерии, ошибки, объяснённые ответы самопроверки и источники. [Полная карта с результатами и временем](../resources/course-map.md) позволяет выбрать отдельную тему.

## Последовательность

1. **Вопрос → этика → поиск → оценка источников → сохранение.** Уроки 01–05 завершаются [проектом 01](../practice/projects/01.md): планом и редакционной запиской.
2. **Изображение → видео → место → время → карты.** Уроки 06–10 завершаются [проектом 02](../practice/projects/02.md): карточкой визуальной проверки.
3. **Компании → инфраструктура → публичные посты → связи → данные.** Уроки 11–15 завершаются [проектом 03](../practice/projects/03.md): проверкой контракта и выплат.
4. **Python по желанию → дезинформация и ИИ → отчёт.** После 17–18 соберите [итоговый кейс](../practice/capstone.md).

Все обязательные лабораторные выполняются на [локальном синтетическом корпусе](../assets/case/README.md). Регистрация, платная подписка и API для них не нужны. Модуль 16 можно пропустить без потери дальнейшего маршрута. На весь обязательный путь планируйте 26–34 часа; подробный расчёт дан в карте.

## Выбрать ритм

- **Проба за 15 минут:** [проверить сумму выплат](../resources/quickstart.md).
- **Последовательное обучение:** [план на 30 дней](../resources/30-days.md).
- **Уже есть опыт:** прочитайте [карту](../resources/course-map.md), выполните три проекта и используйте рубрики для поиска пробелов. Это самопроверка, не экзамен на квалификацию.
