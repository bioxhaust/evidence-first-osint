## Метод

**Переменная** даёт имя значению, **список** хранит последовательность, **словарь** связывает имена полей со значениями. `csv.DictReader` читает строки CSV как словари: выражение `row['status']` получает статус текущей записи. Цикл `for` повторяет действия для каждой строки; отступы задают, какие действия входят в цикл. Условие `if` пропускает или принимает запись согласно явному правилу.

CSV-поля первоначально являются текстом. Для денег используем `Decimal`, чтобы не вводить ошибку двоичного `float`; даты преобразуем через `date.fromisoformat`. Контекстный менеджер `with` закрывает файл после чтения. Явная UTF-8-кодировка и `newline=''` предотвращают часть различий между средами. Исходный файл открывается только для чтения.

**JSON** хранит структурированные значения: объекты, списки, числа и строки. Ответ API в JSON не становится достоверным только потому, что его легко разобрать. Нужно проверить схему, смысл полей, дату и полноту результата. Пагинация может означать, что один ответ содержит лишь часть записей.

**API** — согласованный интерфейс запросов и ответов. До автоматизации проверяйте разрешённый сценарий, авторизацию, лимиты, условия хранения и правила обработки персональных данных. Для маленького исследования один разрешённый запрос лучше бесконтрольного цикла. При 401/403 останавливайтесь и проверяйте доступ; при 429 — соблюдайте ограничение и указания сервиса. Ключи никогда не помещайте в код, журнал или репозиторий.

## Разобранный пример

1. Сохраните следующий код в собственный файл `first_analysis.py` в корне репозитория. Он предназначен для **чистого** CSV с уникальными платежами, а не для произвольных внешних таблиц.

```python
import csv
import json
from datetime import date
from decimal import Decimal

cutoff = date(2025, 5, 18)
selected = []
total = Decimal("0")

with open("docs/assets/case/payments.csv",
          encoding="utf-8", newline="") as handle:
    for row in csv.DictReader(handle):
        if row["contract_id"] != "C-17":
            continue
        if row["currency"] != "TST" or row["status"] != "settled":
            continue
        if date.fromisoformat(row["paid_at"]) > cutoff:
            continue
        total += Decimal(row["amount"])
        selected.append(row["payment_id"])

print(json.dumps({
    "payment_ids": selected,
    "currency": "TST",
    "total_settled_c17": str(total)
}, ensure_ascii=False, indent=2))
```

2. Выполните `python3 first_analysis.py`. Ожидаются PAY-01, PAY-02 и строка суммы `"5000000"`. `continue` означает переход к следующей строке без включения текущей в сумму. Денежная сумма выведена текстом, чтобы не терять точность при последующей передаче JSON.
3. Для грязного CSV запустите готовый вариант с проверками и журналом:

```sh
python3 tools/analyze_case.py docs/assets/case/payments-dirty.csv
```

Проверьте `total_settled_c17: 5000000` и решения в `ledger`: включение, дубликат, карантин, другой договор, неисполненный платёж. Разница между скриптами важна: короткий пример объясняет вычисление, готовый инструмент дополнительно проверяет документированный формат набора и конфликтующие идентификаторы.

4. Прочитайте сохранённый ответ учебного API:

```sh
python3 tools/read_api.py docs/assets/case/api-response.json
```

Ожидаются четыре идентификатора и `count: 4`. Это проверка структуры локального ответа, не вызов внешнего сервиса. Наличие PAY-03 в JSON ещё не означает его исполнение.

### Дополнительно: один публичный запрос

Этот пример получает метаданные открытого репозитория Python через официальный GitHub REST API. Он не исследует людей, не требует токена и не изменяет серверные данные. Перед повторением ознакомьтесь с текущей документацией и лимитами. При ошибке остановитесь; не организуйте цикл повторов.

```python
import json
from urllib.request import Request, urlopen

request = Request(
    "https://api.github.com/repos/python/cpython",
    headers={"User-Agent": "EvidenceFirstCourse",
             "Accept": "application/vnd.github+json"}
)
with urlopen(request, timeout=10) as response:
    raw = response.read(65537)
if len(raw) > 65536:
    raise ValueError("Response exceeds the example's size limit")
data = json.loads(raw)
print(data["full_name"], data["html_url"])
```

Успешный результат `python/cpython` показывает получение одного объекта. Он не доказывает качество кода репозитория и не даёт права считать любой API бесплатным или доступным без регистрации. Если сеть недоступна, локальная часть урока остаётся полностью выполнимой.

## Ошибки и ограничения

Успешное завершение программы не гарантирует правильный вопрос исследования. Скрипт может без ошибок сложить неверно выбранные строки. Короткий пример предполагает чистые данные; не применяйте его к `unknown` без валидации. Не устанавливайте случайные пакеты ради чтения CSV: здесь достаточно стандартной библиотеки. Поддержка конкретных сред и результаты запусков перечисляются в документации проекта, а не выводятся из одного примера.

## Самопроверка

1. **Зачем `Decimal`, если суммы здесь целые?** Он сохраняет точную десятичную арифметику и задаёт безопасный подход для денежных данных; обычный `float` может вносить округления.
2. **Что доказывает `count: 4`?** Наличие четырёх записей в прочитанном локальном JSON. Оно не доказывает четыре исполненных платежа или полноту внешнего реестра.
3. **Нужно ли повторять запрос сразу после 429?** Нет. Это сигнал ограничения; следует соблюдать политику API и время ожидания, а не обходить лимит.
