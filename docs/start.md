# Как начать

[Открыть лабораторию расследований](investigator/index.md){ .md-button .md-button--primary }

Откройте исходную страницу и найдите нужный профессиональный профиль среди трёх кандидатов. Сохраните ссылку, цитату и основание выбора. Для первой находки достаточно браузера и заметок — установка программ будет следующим шагом.

## Сначала — самостоятельное действие

Пройдите [практический маршрут](practice/fieldwork.md): три самостоятельных расследования, настоящий Sherlock и Maigret, извлечение метаданных и видеокадров с ExifTool/FFmpeg. В каждом задании есть исходные материалы, сдаваемый результат, подсказки и отдельный разбор. Ориентир — 4–6 часов плюс первая установка; это оценка. Часть заданий пересекается с базовым курсом.

Теорию открывайте по ссылке из задания, когда она нужна для следующего шага. [Инструментарий](resources/toolkit.md) помогает выбрать программу под вопрос, а [тренажёр](trainer/index.md) — закрепить решения после практики. Самостоятельные отчёты проверяются по рубрикам: XP их автоматически не оценивают.

## Дополнительные пути: закрепить и углубить

**Тренажёр:** 20 блоков, 60 микроупражнений, примерно 2–3 часа. Он помогает освоить отдельные решения; прохождение кнопками не заменяет файлы и отчёты лабораторных. Для автоматической проверки нужен JavaScript. Прогресс пока сохраняется в текущем браузере. Вход через GitHub и облачная синхронизация не включены до завершения настройки провайдера; это отложенный следующий этап. [Проверки и ограничения](about/quality.md).

**Полный курс:** 20 модулей и 20 лабораторных; только 16 о программировании на Python/API дополнительный. Обязательный маршрут — 19 модулей, три проекта и итоговый кейс: номинально 27 ч 45 мин, с исправлениями 28–36 часов. Вместе с тренажёром — 30–39 часов. Все времена оценочные.

Сначала проходят страницы 19 и 20, затем 01–18. Их номера сохранены для постоянных ссылок. [Карта](resources/course-map.md) и [30-дневный план](resources/30-days.md) уже учитывают этот порядок.

## Что подготовить

Скачайте GitHub → **Code → Download ZIP** и распакуйте проект либо клонируйте репозиторий. Создайте отдельные папки для оригиналов, рабочих копий и отчёта. Не сохраняйте решения поверх исходных файлов.

Для большинства заданий достаточно браузера и текстового редактора. CSV удобнее просматривать в бесплатном табличном редакторе. [Набор профилей](assets/profiles/README.md) и [кейс переправы](assets/case/README.md) содержат все учебные входы.

Во второй обязательной теме вы установите **реальный Sherlock** и запустите его на собственном localhost-стенде. Нужны Python, терминал и интернет для установки пакета; аккаунт, подписка и API-ключ не нужны. Проверенная среда и точные команды — в [лабораторной 20](practice/labs/20.md). Программировать не требуется. Если пока доступно только чтение сохранённого запуска, выполните аналитическую часть и явно оставьте техническую часть незавершённой.

## Как работать с уроком

Обычно урок с лабораторной занимает 60 минут; 16 и 17 — по 75 минут. Сохраните вопрос, действия, исходники, наблюдения, вывод и ограничение в [журнале](templates/journal.md). После своей попытки откройте отдельное решение и сравните основания. Ошибка — уверенно заполнить пробел догадкой; обоснованное «данных недостаточно» может быть правильным итогом.

После 05, 10 и 15 выполните проекты по 90 минут. После 18 — итоговый кейс на четыре часа. Не прибавляйте лабораторные к длительности уроков повторно.

## Дополнительные живые источники

Учебные аккаунты и страницы синтетические. Продолжение на реальных сервисах допускается для собственных или явно согласованных аккаунтов. Изучайте только необходимые публичные данные и правила платформы; в заданиях не нужны частные адреса, контакты и сведения о семье.

Внешние сервисы меняются. [Источники и инструменты](about/sources.md) и [качество](about/quality.md) различают чтение документации, локальный запуск и проверку живой функции.

## Локальный сайт для разработчиков

Для сайта CI использует Python 3.12. Из корня проекта:

~~~sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m mkdocs serve
~~~

Откройте напечатанный MkDocs адрес. Активация выше относится к POSIX-оболочке. Для Sherlock используйте отдельную инструкцию лабораторной, а не подразумевайте одинаковую поддержку сред. Windows-запуск лабораторной здесь не подтверждён.
