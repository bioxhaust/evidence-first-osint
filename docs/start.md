# Как учиться

Начните с [15-минутного исследования](resources/quickstart.md), затем идите по [карте курса](resources/course-map.md). Создайте отдельную папку для своих заметок: `originals`, `working`, `report`. Имена условные; не сохраняйте учебные решения поверх исходников.

Для обязательного маршрута нужен браузер и текстовый редактор. Для таблиц удобен бесплатный LibreOffice Calc, но небольшие CSV читаются и как текст. На странице [корпуса](assets/case/README.md) есть прямые ссылки на все файлы. Чтобы получить весь проект, используйте GitHub → Code → Download ZIP; распакуйте архив. Установка Python и сборка сайта для чтения курса не нужны.

Каждый урок занимает 60 минут, включая лабораторную. Модули 16 и 17 — по 75 минут. Время внутри урока можно распределить так: 20 минут на метод и пример, 30 на лабораторную, 10 на самопроверку и исправления. У некоторых заданий несколько обоснованных ответов: сравнивайте цепочку доказательств, а не формулировку.

После уроков 05, 10 и 15 выполните промежуточный проект. После 18 — итоговый кейс. Модуль 16 дополнительный: пропуск не мешает продолжить 17 и 18. Не открывайте решения до собственной попытки. Присвойте источникам идентификаторы и записывайте неудачные поиски: отрицательный результат полезен, если понятно, что и как проверялось.

## Что сдавать самому себе

Для каждой лабораторной сохраните вопрос, действия, входные файлы, наблюдения, вывод и ограничение. Используйте [журнал](templates/journal.md). Рубрика есть в каждой работе; недостаток исходных данных не является ошибкой, если вы правильно его установили. Ошибка — скрыть этот недостаток уверенным выводом.

## Дополнительные живые источники

В уроках есть официальная документация поисковиков, реестров, карт и API. Это расширение локальной практики. Доступность интерфейсов зависит от региона и изменений сервиса; дата проверки — 2026-11-03. [Страница источников](about/sources.md) различает чтение документации и работу сервиса. Курс не обещает, что все инструменты доступны без регистрации во всех странах.

## Локальный сайт для разработчиков

В корне распакованного проекта, в терминале с Python 3.12:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m mkdocs serve
```

Откройте адрес, который напечатает MkDocs. Команда активации выше для POSIX-оболочки. Для PowerShell обычно используется `.venv\Scripts\Activate.ps1`; Windows-инструкция не была проверена запуском. Сведения о фактических проверках — на [странице качества](about/quality.md).
