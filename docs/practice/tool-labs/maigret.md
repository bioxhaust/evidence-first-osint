# Maigret: получить отчёт, найти ошибку и исправить правило

**Задание:** вам прислали результат автоматического поиска учебного ника `route_lab`. Можно ли передать JSON заказчику как полный список проверенных страниц? Запустите Maigret сами, сравните два экспорта, проверьте найденные страницы и исправьте одно правило обнаружения.

**После задания у вас будут:** собственные JSON и CSV Maigret, журнал четырёх проверок и повторный запуск с исправленным правилом. Вы сможете объяснить, почему две программы иногда уверенно повторяют одну ошибку.

Ориентир — **45–60 минут после установки**. Скачайте репозиторий курса через GitHub → **Code → Download ZIP**, распакуйте и откройте терминал в его корневой папке. Все команды ниже выполняются из неё. Страницы вымышлены и обслуживаются вашим компьютером; аккаунт Maigret, API-ключ и подписка не нужны. Полезно сначала выполнить [Sherlock-лабораторную](../labs/20.md), но её результат не подменяет этот запуск.

## 1. Установите настоящий инструмент

Проверьте `python3 --version`. Для этого упражнения проверен **Python 3.12.11**, macOS arm64, **Maigret 0.6.6**. Если команда `python3` указывает на другой интерпретатор, используйте имя установленного Python 3.12 в первой строке. Не устанавливайте пакет в системную среду и не используйте `sudo`.

```sh
python3 -m venv scratch/maigret312-venv
scratch/maigret312-venv/bin/python -m pip install maigret==0.6.6
scratch/maigret312-venv/bin/maigret --version
scratch/maigret312-venv/bin/maigret --help
```

Установка скачивает сторонние зависимости и требует интернета; первый запуск установки может занять несколько минут. Найдите в справке `--db`, `--json`, `--csv`, `--no-recursion`, `--no-extracting`, `--timeout`. Запишите, что делает каждый параметр. Команды выше используют POSIX-пути macOS/Linux; выполнение на Windows отдельно не проверялось.

Maigret умеет находить кандидатов по username, извлекать дополнительные сведения и выпускать отчёты. В этой лабораторной задача уже: проверить обнаружение и экспорт. Извлечение дополнительных данных и рекурсия отключены; их наличие в программе не делает каждый результат доказательством принадлежности человеку.

## 2. Получите собственный результат

В первом терминале запустите учебные страницы:

```sh
python3 tools/profile_fixture_server.py
```

Оставьте этот терминал открытым. Сообщение должно указывать `http://127.0.0.1:54369`. Во втором терминале, тоже из корня курса:

```sh
scratch/maigret312-venv/bin/python tools/run_maigret_local.py
```

Launcher вызывает **настоящий CLI установленного Maigret**, передавая [базу четырёх страниц](../../assets/profiles/maigret-local-sites.json). Он сохраняет три файла в `scratch/maigret-run-01/`:

- `report_route_lab_simple.json` — собственный JSON-экспорт Maigret;
- `report_route_lab.csv` — собственный CSV-экспорт Maigret;
- `local-run.json` — версия, параметры, хеш базы и счётчики защитного кода курса.

Скопируйте терминальный вывод в свой журнал. Последний файл — **служебная запись курса**, а не дополнительный формат отчёта Maigret. Если папка первого запуска уже существует, укажите новую: `--output scratch/maigret-repeat-01`. Launcher специально не перезаписывает прошлую попытку.

<details markdown>
<summary>Что именно запускает launcher и что ограничивает</summary>

Он вызывает функцию CLI `maigret.maigret.main` через `asyncio.run`, с одним username, локальным `--db`, `--json simple`, `--csv`, `--timeout 0.25`, `--retries 0` и четырьмя соединениями. Автообновление базы, рекурсия и извлечение дополнительных сведений отключены. Используются только встроенные настройки пакета, без пользовательского, системного и проектного `settings.json`.

Перед запуском проверяется версия и структура базы; разрешены только четыре учебные записи и URL `127.0.0.1:54369`. Прокси из окружения не наследуются. Guard ограничивает стандартные Python-сокеты и разрешение адресов, включая последующие TCP-соединения. Это **не системная песочница**, не встроенная гарантия Maigret и не защита для произвольного стороннего кода. Файлы установленного пакета не меняются. В проверенном пути используется aiohttp с threaded DNS resolver и числовым localhost-адресом.

[Исходник launcher](https://github.com/bioxhaust/evidence-first-osint/blob/main/tools/run_maigret_local.py) можно прочитать до запуска. Не переносите его гарантии на другую версию, базу сайтов или режимы программы.
</details>

## 3. Проверьте экспорт и страницы

Откройте CSV и JSON как текст. Найдите поля `exists`, `http_status`, `error_reason` в CSV. Сравните названия проверенных сайтов в обоих файлах. **Какие строки пропали из JSON и почему?** Пока не открывайте решение.

Для каждого URL из CSV откройте страницу в браузере, пока сервер работает. Прочитайте текст, а не только HTTP-статус. Заполните четыре короткие записи:

```text
Название сайта и URL:
Что написал Maigret (дословно, из CSV):
Что я сам увидел на странице (цитата):
Моё решение: профиль / общая страница / отсутствие по маркеру / неизвестно
Основание и ограничение:
```

Если медленная страница позже открылась в браузере, разделите два наблюдения: первоначальный запрос Maigret завершился тайм-аутом, последующая ручная проверка получила ответ. Не переписывайте старый результат так, будто программа получила его сразу.

<details markdown>
<summary>Подсказка: экспорт кажется короче поиска</summary>

В этой версии `--json simple` сохраняет только результаты со статусом `CLAIMED`. CSV сохраняет и другие исходы. Отсутствие сайта в JSON само по себе не говорит, проверялся ли он, отсутствовал ли профиль или запрос завершился ошибкой. Сохраните оба формата.
</details>

<details markdown>
<summary>Подсказка: два плюса, но страницы выглядят по-разному</summary>

У двух записей разные `checkType`. `status_code` считает ответ 2xx положительным, а `message` проверяет текстовые маркеры. Найдите страницу, которая выдаёт 200, но прямо сообщает об отсутствии профиля. Выпишите точный фрагмент её текста.
</details>

## 4. Исправьте одно правило и измерьте изменение

Сохраните оригинальную базу и сделайте рабочую копию:

```sh
cp docs/assets/profiles/maigret-local-sites.json scratch/maigret-rules.json
```

Откройте копию в текстовом редакторе. Найдите запись, которая дала ложный плюс. Замените её `checkType` на `message` и добавьте `absenceStrs` — массив с **дословным маркером отсутствия из страницы**. Остальные записи не меняйте. Это реальный формат Maigret; название `presenseStrs` в исходной базе содержит именно такое историческое написание.

Повторите проверку, пока первый терминал с сервером открыт:

```sh
scratch/maigret312-venv/bin/python tools/run_maigret_local.py --database scratch/maigret-rules.json --output scratch/maigret-run-02
```

Сравните старый и новый CSV: какая строка изменилась, какие остались прежними? Объясните, почему ваша правка работает на этой странице и что случится, если сайт поменяет текст. По окончании остановите сервер в первом терминале сочетанием `Ctrl+C`.

## Что сдать

Сохраните два каталога запусков, исправленную базу и четыре ручные записи. Добавьте вывод из 4–6 предложений: сколько найдено проверяемых профилей в исходном запуске, почему JSON неполон, что изменило исправление, какое наблюдение остаётся технически неопределённым и какая проверка нужна дальше.

Оценка **10 баллов**: 2 — собственные два запуска с версиями и файлами; 2 — обнаружена разница JSON/CSV; 2 — ложный плюс опровергнут цитатой страницы; 2 — исправлено одно правило и сохранено сравнение; 2 — тайм-аут, принадлежность аккаунта человеку и предел применимости правила описаны отдельно. Чтение сохранённого чужого вывода не даёт баллов за собственный запуск.

## Если не получилось

- **`No module named maigret`:** проверьте, что запускаете Python именно из `scratch/maigret312-venv/bin/`, а установка завершилась успешно.
- **Ошибка создания venv или установки:** сохраните сообщение и версию Python. Проверьте работоспособный Python 3.12; отсутствие среды не исправляется подменой вывода программы готовым ответом.
- **`Address already in use`:** возможно, ваш Sherlock-стенд ещё работает. Используйте свой уже запущенный сервер или остановите именно его. Не завершайте неизвестный процесс на порту.
- **Все строки показывают ошибку подключения:** проверьте первый терминал и URL `http://127.0.0.1:54369/present/route_lab` в браузере. Сетевые ошибки не означают отсутствие четырёх профилей.
- **Launcher отклонил базу:** оставьте четыре исходных сайта и localhost-URL; редактируйте только правило распознавания в рабочей копии. Проверьте запятые и кавычки JSON.
- **Предупреждение о 25% тайм-аутов:** один из четырёх ответов намеренно задержан. Совет Maigret сменить провайдера — общее сообщение программы, не диагноз этой локальной ситуации.
