# Лабораторная: Sherlock на страницах с известным ответом

**Время: 35 минут, входит в основной [урок инструментов](../../lessons/20-github-tools.md).** Цель — запустить настоящий Sherlock 0.16.2 и объяснить его правильный результат, ложное срабатывание и тайм-аут. Первичная установка Python может занять дополнительное время.

## Входные данные

Клон курса, официальный пакет `sherlock-project==0.16.2`, [локальная база сайтов](../../assets/profiles/sherlock-local-sites.json), сервер `tools/profile_fixture_server.py` и launcher `tools/run_sherlock_local.py`. Эти оригинальные учебные страницы не относятся к реальным людям или платформам.

## Запуск — два терминала

Команды выполняются из корня курса. Проверены macOS arm64 и Python 3.14.6; на Windows пути к исполняемым файлам виртуальной среды отличаются, такой запуск здесь не подтверждён.

1. Подготовьте среду и прочитайте справку:

   ```sh
   python3.14 -m venv scratch/sherlock-venv
   scratch/sherlock-venv/bin/python -m pip install sherlock-project==0.16.2
   scratch/sherlock-venv/bin/sherlock --help
   ```

2. В первом терминале запустите локальный сервер:

   ```sh
   python3 tools/profile_fixture_server.py
   ```

   Он слушает только `127.0.0.1:54369`. Если порт занят, не останавливайте неизвестный процесс: сначала установите причину и отметьте запуск как незавершённый.

3. Во втором терминале выполните:

   ```sh
   scratch/sherlock-venv/bin/python tools/run_sherlock_local.py
   ```

   Launcher вызывает установленный Sherlock main. Его Requests-guard запрещает запросы за пределы учебного адреса, включая автообновление. Не заменяйте команду на обычный поиск username без custom JSON.

4. Сохраните фактический вывод. Для `Present`, `Soft404`, `Missing`, `Slow` запишите: ответ программы → известное поведение страницы → допустимый вывод. Откройте локальную страницу `/soft404/route_lab` в браузере или прочитайте её текст в функции `fixture_response` сервера: это общая страница с HTTP 200, а не профиль.
5. Сравните строку guard: четыре локальных запроса, одна заблокированная внешняя попытка обновления. Затем завершите сервер `Ctrl+C` в первом терминале.

## Следующая проверка

Обработайте сохранённые кандидаты предыдущей лабораторной отдельной программой:

```sh
python3 tools/profile_candidates.py docs/assets/profiles/scanner-results.json docs/assets/profiles/profiles.json
```

Это офлайн-анализ **вымышленного TrainingScanner**, не импорт вывода Sherlock. Сверьте пять карточек и шесть строк журнала. Объясните разницу между ошибкой определения страницы Soft404 и ошибкой объединения личности PR03.

Откройте официальный README Maigret или ExifTool. Составьте карточку: задача; лицензия; зависимости; что программа передаёт в сеть или меняет в файлах; проверенная версия; ограничение. Второй инструмент устанавливать не требуется: вы уже выполнили практический запуск Sherlock.

## Что сдать

Версию Python/Sherlock, три команды, фактический вывод, четыре объяснения локальных ответов, результат офлайн-сверки и карточку второго проекта. Если возможен только [разбор сохранённого запуска](../../assets/profiles/sherlock-run.json), честно отметьте техническую часть как невыполненную и запланируйте собственный запуск; чтение лога не заменяет его.

## Рубрика — 10 баллов

- 3: реальный запуск, версии и команды воспроизводимы; только локальные цели.
- 3: Soft404 распознан как ложное срабатывание, тайм-аут не назван отсутствием.
- 2: кандидаты не объединены по одному username, сохранён журнал дубля.
- 2: выбор второго инструмента основан на задаче, лицензии и зависимостях.

Без собственного запуска возможны баллы за анализ, но техническая часть остаётся незавершённой. Нет необходимости исследовать реального человека, чтобы получить все баллы.
