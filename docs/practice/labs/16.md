# Лабораторная 16. Необязательный маршрут Python

**Время:** 35 минут, входит в [дополнительный урок 16](../../lessons/16-python.md). **Результат:** повторяемый локальный расчёт и честный журнал запуска. Пропуск лабораторной не мешает основному маршруту.

## Входные данные

Клон репозитория, `tools/analyze_case.py`, `tools/read_api.py`, [payments-dirty.csv](../../assets/case/payments-dirty.csv), [api-response.json](../../assets/case/api-response.json). JSON — синтетический локальный ответ, а не результат обращения к действующему API.

## Задача

Используйте стандартную библиотеку Python для проверки уже выполненного ручного расчёта. Ключи API, сетевые запросы и сторонние библиотеки для этой работы не требуются.

1. В корне репозитория запишите версию `python3 --version`. Если команда недоступна, воспользуйтесь инструкцией урока или пропустите дополнительный маршрут с явной отметкой.
2. Выполните:

   ```sh
   python3 tools/analyze_case.py docs/assets/case/payments-dirty.csv
   python3 tools/read_api.py docs/assets/case/api-response.json
   ```

3. Сохраните вывод обеих команд и сопоставьте первый итог с ручной лабораторной 15. Прочитайте, какие строки исключены или признаны ошибочными.
4. Прочитайте код разбора CSV: найдите применение `csv`, числовую проверку, условие статуса и контракта. Объясните один из фильтров своими словами.
5. В отдельной рабочей копии удалите обязательный столбец либо замените числовую сумму неверной строкой. Запустите анализатор на этой копии. Запишите фактическое поведение; не подменяйте ожидаемым.
6. Объясните, чем чтение локального JSON отличается от настоящего API: авторизация, статус HTTP, ограничения, пагинация, время среза. Живой API не вызывайте ради получения балла.

## Что сдать

Версию Python, команды, выводы и 150 слов об одном фильтре и одном ограничении. Исходный корпус не изменяется.

## Рубрика — 10 баллов

- 3: оба запуска воспроизводимы и задокументированы.
- 2: результат сопоставлен с ручным расчётом.
- 3: выполнена и объяснена проверка некорректной рабочей копии.
- 2: локальная симуляция не названа проверкой живого API.

**Типичная ошибка:** скрипт завершился — значит входные данные полны и правдивы.
