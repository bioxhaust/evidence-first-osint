# Разбор: настоящий Sherlock и ложное срабатывание

[Вернуться к заданию](../../practice/labs/20.md).

## Что показал проверенный запуск

Sherlock 0.16.2 действительно запущен в отдельной среде Python 3.14.6 на macOS arm64 2026-11-03. [Сохранённая выдержка](../../assets/profiles/sherlock-run.json) относится к этому запуску, а не к смоделированному ответу программы.

- **Present: плюс.** Сервер возвращает профиль LEARNER-A; в известной модели результат обнаружения верен. Он всё ещё не является доказательством юридической личности.
- **Soft404: плюс.** Сервер возвращает HTTP 200 с текстом общей страницы, где прямо сказано, что профиля нет. Выбранная эвристика `status_code` приняла успешный HTTP-ответ за наличие аккаунта. Это намеренно воспроизводимое ложное срабатывание.
- **Missing: Not Found.** Здесь используется `message` и заданный маркер `PROFILE NOT FOUND`. Правило соответствует ответу этой учебной страницы. Из его успеха не следует, что оно будет правильно распознавать все настоящие сервисы после изменения их интерфейсов.
- **Slow: Timeout Error.** Сервер задерживает ответ на одну секунду, а CLI использует тайм-аут 0,25 секунды. Состояние аккаунта из незавершённого запроса не установлено.

В конце Sherlock пишет `Search completed with 2 results`. Один из двух результатов ложный. Поэтому число найденных ссылок без чтения страниц не является числом подтверждённых аккаунтов.

## Почему в начале есть сообщение об обновлении

Upstream CLI пытается проверить новую версию даже при custom JSON. Учебный guard блокирует эту попытку в Requests до сетевого обращения. Строка `LOCAL_GUARD local_requests=4 blocked_external_attempts=1` относится к наблюдаемым отправкам через этот путь. Это не обещание универсальной системной изоляции любого Python-кода. `--ignore-exclusions` здесь относится только к четырём собственным тестовым правилам, не к реальному поиску.

Отдельная среда устанавливает зависимости, но не ограничивает сетевые права. Поэтому «я создал venv» не заменяет проверку фактически вызываемых адресов.

## Сопоставление кандидатов и выбор инструмента

Офлайн-программа на другом наборе даёт: шесть исходных строк, пять уникальных карточек, две подтверждённые в корпусе связи, один кандидат, две неизвестности. Дубль PR01 сохранён в журнале. PR03 показывает другой тип ошибки: страница, похожая на профиль, есть, но принадлежность LEARNER-A не установлена. Это отличается от Soft404, где ошибочно распознано само наличие профиля.

Для выбора второго проекта допустимы разные карточки. Maigret полезен при согласованном поиске username и дополнительных публичных сведений, но требует проверки объёма сбора, сетевых обращений и зависимостей; лицензия MIT не даёт права свободно обрабатывать чужие данные. ExifTool полезен для собственного файла: прочесть метаданные перед публикацией. Следует различать чтение и запись, работать с копией и сверять лицензию README, а не только автоматически определённый бейдж GitHub.

Если установка, порт или импорт завершились ошибкой, правильная сдача содержит её фактический текст и следующий шаг. Скопированный успешный вывод не получает баллы за запуск. В других средах возможны иные сообщения; смысл результата проверяют по поведению стенда и исходникам конкретной версии.
