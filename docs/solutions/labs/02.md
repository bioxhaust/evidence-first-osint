# Разбор лабораторной 02

[Вернуться к заданию](../../practice/labs/02.md).

Для проверки контракта достаточно `contract_id`, `supplier_id`, реестрового идентификатора, суммы, статуса и даты платежа. Личный адрес сотрудника не помогает установить сумму расчёта. Публикация такого адреса может создать риск преследования; покупка утечки выходит за учебный периметр и не становится приемлемой из-за удобства.

Рабочая формулировка: «В этом упражнении обрабатываются только явно синтетические материалы корпуса. В реальном проекте до сбора проверяются применимое право, условия источника, права на распространение и необходимость каждого поля. Публичная версия содержит только относящиеся к вопросу доказательства. Лишние персональные сведения не собираются; случайно полученные отделяются от публикации и обрабатываются по заранее установленной процедуре».

Не существует единственного правильного срока хранения для всех редакций. Допустим, вы предложили пересмотреть рабочие копии через 30 дней после публикации: это организационное решение, а не норма GDPR. Для реального проекта нужен обоснованный срок с учётом обязательств сохранения доказательств и прав участников. В упражнении исходные синтетические файлы можно хранить свободно в пределах лицензии.

GDPR следует обсуждать как право ЕС с материальной и территориальной областью применения; наличие европейского сайта само по себе не решает все вопросы. Не нужно выдумывать местное право для TRAIN-A: это учебная метка, не государство.

**Недостаточно данных:** по открытому названию компании нельзя определить, какие законы применимы ко всем действиям конкретного исследователя. Успешный протокол фиксирует необходимость установить контекст, а не придумывает разрешение.
