# Разбор лабораторной 05

[Вернуться к заданию](../../practice/labs/05.md).

Универсального заранее напечатанного проверенного хеша здесь намеренно нет: ожидаемое значение находится в манифесте выбранной версии корпуса, а фактическое получают из байтов локального файла. В основном маршруте допустимо записать «значение из манифеста; не пересчитывалось». В дополнительной технической части совпадение означает, что ваша копия соответствует эталону этой поставки. Если файл скачан через просмотр страницы GitHub как HTML вместо Raw-файла, хеш будет иным — это полезный диагностический случай, а не повод подгонять результат.

Пример записи без выдуманной контрольной суммы: «E02, `bulletin-01.txt`, скачан по ссылке из индекса корпуса; время получения записано локально с часовым поясом; SHA-256 вычислен установленной программой; совпадение с манифестом подтверждено; относится к режиму движения 17 мая». В своей работе замените описание проверки фактическим вычисленным значением.

После добавления строки изменятся байты, а следовательно, ожидается другой SHA-256. Запись производной копии должна назвать E02, характер правки и новое имя. Обратное восстановление исходника из хеша невозможно; сам исходник нужно сохранить.

Хеш не устанавливает автора, время первой публикации, правдивость текста или законность получения. Манифест и файл из одного недоверенного места могут быть изменены вместе. В настоящем расследовании происхождение закрепляют отдельно: источником, временем, способом фиксации и процедурами хранения.

При отсутствии утилиты можно сохранить ожидаемую сумму и описать будущую проверку командой из урока. Это полноценный результат основного маршрута, если происхождение и изменения отражены верно. Отметка «целостность проверена» остаётся недоступной до реального вычисления. Python из дополнительного маршрута — ещё один способ пересчёта, но устанавливать его ради этой лабораторной не требуется.
