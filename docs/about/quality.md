# Проверки качества и ограничения

Проверено **3 ноября 2026 года**. Текущий состав: **20 модулей, 20 лабораторных, три промежуточных проекта, один итоговый кейс и тренажёр из 20 блоков / 60 заданий**. Только модуль 16 о программировании на Python/API дополнительный. Сохранённые отчёты разделяют реальные запуски, имитацию ответов и редакторское чтение.

## Что доступно в этом выпуске

Курс и тренажёр работают с локальным прогрессом в браузере. **GitHub-вход и облачная синхронизация пока не включены:** завершение настройки OAuth-провайдера отложено на последующий этап. Между разными устройствами прогресс автоматически не переносится. Это текущий этап развёртывания, а не отказ от запланированного входа.

Адаптер, PKCE-обмен и миграция базы подготовлены. Их локальные проверки ниже **не подтверждают** успешный публичный вход, работу живого провайдера или синхронизацию двух реальных устройств. Облачный интерфейс остаётся отключённым до завершения подключения и отдельной проверки.

## Автоматические проверки кода

- **19 из 19 Python-тестов** прошли повторным запуском на macOS arm64, Python **3.12.11**. Проверены очистка чисел, дубликаты, карантин, временная граница, локальный JSON, целостность корпуса, ссылки, классификация профилей, конфликтующие наблюдения и ограничения локальной базы Sherlock. Команда: python -m unittest discover -s tests -v. [Тесты](https://github.com/bioxhaust/evidence-first-osint/tree/main/tests).
- **25 из 25 Node-тестов** прошли повторным запуском на Node **26.7.0**: 14 проверок облачного адаптера и 11 проверок прогресса. Охвачены оценивание, повторение ошибок, необязательный модуль, импорт, конфликтующие вкладки, смена аккаунта, черновики, PKCE и устаревшие ответы. Ответы облака синтетические. Команда: node --test tests/cloud.test.mjs tests/trainer-progress.test.mjs. [Машиночитаемый протокол](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-trainer-ui.json).
- **13 из 13 PostgreSQL-проверок** прошли на реальном временном PostgreSQL **16.15**, без TCP и подключения к действующей базе. Проверены применение миграции, запрет анонимного доступа, изоляция строк пользователей, конфликт ревизий и валидация состояния. Роли Supabase и auth.uid() имитировались; живой Supabase Auth не испытывался. [Протокол базы](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-cloud-database.json), [повторяемый тест](https://github.com/bioxhaust/evidence-first-osint/blob/main/tests/cloud_database.py).
- **8 из 8 дополнительных JSDOM-сценариев** прошли на JSDOM **30.1.3**. Настоящий код интерфейса, прогресса и заданий работал с управляемой имитацией облака. Проверены сохранность выбранных ответов и числового черновика, поздняя синхронизация после выхода, неподтверждённая сессия, ошибка OAuth, пропуск дополнительного Python изменения другой вкладки и чистый ответ в новой попытке повторения. Это DOM-проверки, не визуальный браузерный тест. Временный стенд не включён в репозиторий и не входит в постоянные 25 Node-тестов. [Подробный отчёт](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/trainer-ui-review.md).

Эти четыре числа нельзя складывать и представлять как единую постоянную тестовую серию: у проверок разные среды, способы запуска и воспроизводимость.

## Настоящий Sherlock и учебные данные

**Sherlock 0.16.2 действительно запущен** на четырёх синтетических localhost-страницах, macOS arm64, Python **3.14.6**. Получены Present — найден, Soft404 — ложный положительный результат HTTP 200, Missing — отсутствие по заданному маркеру, Slow — тайм-аут. Launcher ограничил Requests локальным адресом: четыре локальных запроса и одна заблокированная до выхода в сеть попытка обновления.

[Сохранённый фактический вывод](../assets/profiles/sherlock-run.json), [локальная база](../assets/profiles/sherlock-local-sites.json), [лабораторная](../practice/labs/20.md). Guard — код учебного стенда, а не системная песочница или встроенная гарантия Sherlock. Живые платформы этим запуском не проверены. Изучение сохранённого лога не заменяет собственный запуск участника.

Отдельный **вымышленный TrainingScanner** используется для сопоставления профилей. Локальный анализатор реально вернул: шесть строк, пять уникальных кандидатов, две подтверждённые заявленные связи, один кандидат, два неизвестных результата. Его данные не выдаются за экспорт Sherlock. [Корпус профилей](../assets/profiles/README.md).

Для кейса переправы реально проверены:

- Фильтрация платежей C-17: PAY-01 и PAY-02 дают **5 000 000 TST**; дубль, плановая запись, другой контракт и неизвестная сумма сохраняют свои причины исключения.
- Локальный API JSON содержит четыре записи. Два Python-блока урока 16 выполнены: локальный расчёт и один неаутентифицированный GitHub REST-запрос к python/cpython.
- EXIF времени есть только в исходной иллюстрации; часовой пояс и GPS отсутствуют. У репоста EXIF времени нет. Проверено чтением метаданных, включая ExifTool **13.50**.
- FFprobe подтвердил шестисекундный H.264 MP4: 1200×760, 12 кадров/с, 72 кадра.
- Исходные 25 файлов корпуса переправы пересозданы во временной папке с совпадением SHA-256 в проверенной macOS-среде. Это не утверждение о побайтовой идентичности на всех системах.

[Протокол запуска корпуса](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-runtime.json) относится именно к этим данным; [технический отчёт](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/technical-review.md) сохраняет детали.

## Содержание, сборка и интерфейс

У всех 20 уроков есть результат, подготовка, метод, разобранный пример, самостоятельная работа, критерии, ограничения, объяснённая самопроверка и источники. В лабораторных и проектах есть входы, сдаваемый результат и рубрика. Банк тренажёра импортирован как ESM: 60 уникальных заданий, корректные варианты ответов, подсказки и ссылки. [Проверка банка](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/trainer-bank-review.md).

Исходные 18 уроков и их практика прошли [отдельный редакторский разбор](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/curriculum-review.md). Новые профильные темы сверены с локальным корпусом, документированными командами и [исследованием GitHub-инструментов](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/profile-tools-review.md). Это внутренний просмотр агентами, не внешняя экспертная аккредитация.

Сборка `mkdocs build --strict` и `tools/check_project.py` прошли: **103 HTML-страницы, более 9 600 внутренних ссылок и якорей**, все 20 уроков и лабораторных на месте. [Точный протокол интеграции](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-integration.json). Отдельно проверены все **100 ссылок тренажёра на 66 целей**: уроки, лабораторные и файлы данных корректно разрешаются с префиксом GitHub Pages.

В браузере Codex на macOS проверен окончательный тренажёр на ширинах **375, 550, 812, 1280 и 1440 px**. На просмотренных экранах боковой прокрутки нет. Проверены светлая/тёмная темы, неверный и правильный ответы, 30 XP за три задания, открытие второго блока, повторение без готовых ответов и дополнительных XP, сохранение после перезагрузки, скачивание и импорт резервной копии. [Протокол тренажёра](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-trainer-browser.json).

[Ранний браузерный протокол](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-browser.json) дополнительно фиксирует поиск, переходы уроков, раскрытие челленджа и клавиатурное меню. Это выборочные проверки в настольном браузере: физический телефон, экранный диктор и полное соответствие WCAG не проверялись.

## Источники и права

Обзор десяти открытых ресурсов сохранён с датой, ссылками и границами просмотра. Внешние HTTP-проверки подтверждают получение страницы, а не исправность всех функций сервиса. [Ранний протокол внешних ссылок](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-all-external-links.json) охватывает первоначальный набор; новые инструменты имеют отдельный отчёт. Пустой HTTP 202 EUR-Lex и ограниченные ответы OHCHR не выдаются за прочитанный нормативный текст. [Источники](sources.md).

Учебные объекты и страницы синтетические, маркированные и созданы для распространения. Сторонние книги и полные страницы не перепубликуются. Собственный текст и данные — [CC BY 4.0, код — MIT](licenses.md); upstream-инструменты сохраняют свои лицензии. Автоматический поиск известных форматов секретов не является гарантией отсутствия любых персональных данных или полной юридической экспертизой.

## Известные ограничения

- GitHub OAuth и облачная синхронизация ожидают завершения подключения провайдера и проверки на опубликованном сайте. Пока работает локальное сохранение в текущем браузере; очистка данных браузера может удалить прогресс.
- Нет пилота на начинающих учащихся или независимой сертификации. **28–36 часов** курса, **2–3 часа** тренажёра и **30–39 часов** вместе — оценки.
- Уроки, лабораторные, тренажёр и решения не переведены полностью на английский.
- Локальные запуски проверены на указанных macOS-средах. Windows, все варианты Linux, живые платформы Sherlock и экранные дикторы не объявляются поддержанными без отдельных проверок.
- Синтетические кейсы тренируют процедуру, но не воспроизводят всю сложность, правовую неопределённость и эмоциональную нагрузку настоящего исследования.
- Ни количество тестов, ни прохождение тренажёра не доказывают профессиональную квалификацию, судебную допустимость или безошибочность выводов.

Сообщить воспроизводимую ошибку можно через [шаблон Issue](https://github.com/bioxhaust/evidence-first-osint/issues/new/choose), приложив безопасный синтетический пример.
