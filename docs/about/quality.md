# Проверки качества и ограничения

Проверка версии 1.0 начата **3 ноября 2026 года**. Ниже разделены выполненные запуски, редакторское чтение и ограничения. Число файлов и ссылок относится к конкретному состоянию проекта; оно не является оценкой учебной эффективности.

## Выполнено запуском

- Одиннадцать unit-тестов Python для очистки сумм, дубликатов, ошибочных записей, временного среза и проверки локального JSON.
- Сверка 25 учебных файлов с SHA-256-манифестом.
- Анализ платежей: в подтверждённую часть C-17 входят PAY-01 и PAY-02, всего **5 000 000 TST**; остальные записи исключены или сохранены в карантине с причиной.
- Чтение локального API JSON: четыре записи.
- Извлечение метаданных JPEG: EXIF времени есть только в исходной иллюстрации, часовой пояс и GPS не заданы; у репоста EXIF времени отсутствует.
- Проверка MP4 через ffprobe: H.264, 1200×760, 12 кадров/с, 72 кадра, **6 секунд**.
- Выполнение двух Python-блоков урока 16: локальный расчёт и один неаутентифицированный запрос GitHub REST API к python/cpython.
- Пересоздание корпуса во временном каталоге; в проверенной macOS-среде получены те же 25 хешей.

[Технический отчёт](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/technical-review.md) и [машиночитаемые результаты](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-runtime.json) фиксируют конкретные версии и ограничения. Выполнены `mkdocs build --strict` и `tools/check_project.py`: 95 HTML-страниц, более 8 000 проверок внутренних ссылок и якорей, ошибок не найдено. [Точный отчёт интеграции](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-integration.json). JavaScript проверен командой `node --check`.

## Проверка интерфейса

В браузере Codex на macOS проверены ширины 1440×950, 375×812 и 812×375. На просмотренных страницах горизонтального переполнения нет. Проверены поиск «платежи» (17 результатов) и «confidence» (7), переход 01 → 02, открытие решения челленджа, открытие меню с клавиатуры и его закрытие Escape. Просмотрены светлая и тёмная темы; исправлены перенос мобильного заголовка и контраст кнопок в тёмной теме. Это выборочная проверка интерфейса, не полный аудит WCAG или тест на физическом телефоне.

## Содержательная проверка

Прочитаны все 18 уроков, 18 лабораторных и их решения, три проекта и финал. В каждом уроке есть результат, подготовка, метод, пример, самостоятельная работа, критерии, ограничения, самопроверка с объяснениями и источники. Проверены временные интервалы, различие контрактной стоимости и платежей, зависимые репосты, ложные совпадения компаний и границы геолокации.

Исправлены повтор между геолокацией и картографической точностью, несовпадения заданий с уроками, скрытая обязательность технических утилит, тип даты в хронологии и явное отсутствие часового пояса в метаданных. [Редакторский отчёт](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/curriculum-review.md).

## Источники и права

Проверены все 55 уникальных внешних URL на страницах курса. Первый проход: 52 HTTP 200, два пустых ответа EUR-Lex HTTP 202 и один временный 502 crt.sh; повторный запрос crt.sh дал HTTP 200. [Отчёт ссылок](https://github.com/bioxhaust/evidence-first-osint/blob/main/research/evidence/qa-all-external-links.json).

Десять ресурсов исследования и Twint API повторно ответили HTTP 200; замечания об архивном статусе Twint, закрытии OSINT Curious и исторических элементах Verification Handbook подтверждены просмотренными текстами. Это не испытание всех функций чужих сервисов.

[Страница источников](sources.md) отмечает недоступные ответы: например, пустой HTTP 202 EUR-Lex и ограничения OHCHR. Правовые примеры требуют отдельной проверки актуального применимого права. Учебные активы собственные, синтетические, маркированные; полные сторонние страницы и персональные данные не включались. Лицензии разделены на [CC BY 4.0 и MIT](licenses.md).

## Известные ограничения

- Один синтетический кейс не воспроизводит всю сложность, эмоциональную нагрузку и правовую неопределённость реальных расследований.
- Курс создан с помощью ИИ и проверен агентами; независимой экспертной сертификации и пилотирования на новичках нет. Время 26–34 часа — оценка.
- Полного английского перевода уроков и решений нет.
- Авторизованные платные API, обходы доступа и массовый сбор не испытывались и не нужны для основной практики.
- Локальный запуск проверен на macOS; отдельная Linux-проверка подтверждается только успешным GitHub Actions run. Windows и экранные дикторы не испытывались.
- Автоматическая проверка ссылок, alt-текста и известных форматов секретов не гарантирует полного аудита доступности, персональных данных или правовых рисков.

Ошибку можно сообщить через [шаблон issue](https://github.com/bioxhaust/evidence-first-osint/issues/new/choose), приложив безопасный синтетический пример.
