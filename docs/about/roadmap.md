# План развития

Версия 1.0 содержит весь заявленный маршрут. Ближайшие улучшения — завершение подключения GitHub-входа и проверка синхронизации, исправления по отзывам, уточнение оценок времени и проверка изменяющихся внешних ссылок. Затем можно добавить второй оригинальный кейс, провести добровольную апробацию и постепенно переводить уроки на английский.

[Полный roadmap](https://github.com/bioxhaust/evidence-first-osint/blob/main/ROADMAP.md) · [Журнал изменений](https://github.com/bioxhaust/evidence-first-osint/blob/main/CHANGELOG.md)

Это направления работы, не обязательство выполнить их к определённой дате. Платные обязательные зависимости, публикация чувствительных персональных данных и искусственная накрутка популярности не входят в план.
