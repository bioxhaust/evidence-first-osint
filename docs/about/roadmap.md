# План развития

Версия 1.0 содержит весь заявленный маршрут. Ближайшие улучшения — исправления по отзывам, уточнение оценок времени и проверка изменяющихся внешних ссылок. Затем можно добавить второй оригинальный кейс, провести добровольную апробацию и постепенно переводить уроки на английский.

[Полный roadmap](https://github.com/bioxhaust/evidence-first-osint/blob/main/ROADMAP.md) · [Журнал изменений](https://github.com/bioxhaust/evidence-first-osint/blob/main/CHANGELOG.md)

Это направления работы, не обязательство выполнить их к определённой дате. Платные обязательные зависимости, поиск частных лиц и искусственная накрутка популярности не входят в план.
