# Как улучшить курс

Можно исправить факт, объяснение, ссылку, ошибку в задании или перевод. Укажите конкретную страницу, проблему, предлагаемый вариант и первичный источник с датой доступа. Для ошибки кода добавьте безопасный синтетический пример и команду воспроизведения.

[Полные правила участия](https://github.com/bioxhaust/evidence-first-osint/blob/main/CONTRIBUTING.md) · [Создать issue](https://github.com/bioxhaust/evidence-first-osint/issues/new/choose) · [Правила поведения](https://github.com/bioxhaust/evidence-first-osint/blob/main/CODE_OF_CONDUCT.md)

Не прикладывайте персональные данные, токены, утечки и чужие изображения без разрешения. Новые упражнения должны иметь законное происхождение и бесплатную локальную альтернативу. Большое расширение программы сначала обсудите через issue: важно улучшать учебный результат и сохранять воспроизводимость.

Для перевода сохраняйте ссылку на оригинал, одинаковые условия задачи и явный объём готового перевода. Вклад в собственный текст принимается под CC BY 4.0, в собственный код — MIT; авторство не передаётся проекту. Срок ответа сопровождающих не гарантирован.
