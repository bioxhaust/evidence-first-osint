# Маршрут на 30 дней

[Первое дело · 10–15 минут](../practice/investigations/01.md){ .md-button .md-button--primary }

Хотите учиться сразу через действия — начните с [трёх расследований и практикумов инструментов](../practice/fieldwork.md), затем вернитесь к этому месячному плану для углубления. Он описывает прежний базовый курс; новые дела сюда не включены, а выполненный Sherlock повторять не нужно.

Начните с профилей и настоящего запуска инструмента. Постоянные ID первых уроков — **19 → 20**, затем идут **01–18**; номера страниц не задают порядок. Лабораторные уже включены во время уроков. Только программирование на Python/API в модуле 16 дополнительно.

Основной маршрут: **27 ч 45 мин** номинально, ориентир **28–36 часов** с исправлениями. Установка инструмента впервые может занять больше указанного времени. Этот план распределяет работу на месяц, а не устанавливает дедлайн.

Для короткой практики добавьте по одному соответствующему блоку [тренажёра](../trainer/index.md) рядом с уроком: 20 блоков, 60 заданий, отдельные **2–3 часа**. Курс вместе с ними — примерно **30–39 часов**. Микроупражнения не заменяют лабораторные; все оценки редакторские, не измерены на группе.

Готовы 19 обязательных лабораторных, три проекта и итоговый отчёт; техническая часть Sherlock действительно выполнена и записана. Обоснованное «данных недостаточно» принимается по рубрике. Дополнительный модуль 16 и его лабораторная учитываются отдельно. Календарь не присваивает сертификат или квалификацию.
