# Choose a method from the question

[Русский](decision-tree.md)

First define a lawful scope, necessary data and a stopping rule. Then follow the branch that matches the claim:

1. **Unclear claim:** separate subject, action, place, time and prediction. Do not investigate an undefined accusation.
2. **Original publication:** search exact phrases in relevant languages, follow citations and inspect archives. Reposts are not independent confirmation.
3. **Photo/video:** preserve the source, separate caption from visible content, search for earlier appearances and inspect frames. A reverse search result is a lead, not proof.
4. **Location:** compare at least two candidates using the spatial relationships between landmarks. Actively seek contradictions. Report a region or insufficient data if precision is unjustified.
5. **Time:** distinguish file, publication, capture and event timestamps. Normalize explicit offsets; do not invent a timezone for naive metadata.
6. **Company/payment:** establish jurisdiction and registry ID, then join contract and payment records by stable identifiers. A contract amount is not a settled payment.
7. **Website infrastructure:** consult permitted public RDAP, DNS and certificate-transparency information. Shared hosting does not identify a common owner. Active scanning is outside this course.
8. **Many records:** define a schema, matching rules and an audit trail before automation. Quarantine unknown values; preserve raw input.

For every finding ask: Which evidence item supports it? What alternative fits? What would change the assessment?
