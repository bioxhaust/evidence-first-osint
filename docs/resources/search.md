# Поисковые операторы: рабочая шпаргалка

[English](search.en.md) · [Урок с практикой](../lessons/03-search.md)

Проверено по документации Google и Bing **2026-11-03**, без проверки полноты выдачи. Операторы меняются; сервер может интерпретировать запрос иначе. Запишите поисковик, язык, регион, дату, точный запрос и выбранные результаты.

- **Точная фраза:** `"Северная переправа"`. Ищет устойчивую формулировку; может пропустить склонение и перевод.
- **Домен:** `site:example.org "bridge inspection"`. Не ставьте пробел после двоеточия. `site:` не является полным перечнем страниц или проверкой индексации.
- **Тип файла:** `site:example.org filetype:pdf procurement`. Формат PDF не делает документ официальным или достоверным.
- **Исключение:** `"Маяк" -фильм -кино`. Исключение может убрать нужный источник с тем же словом; сначала сохраните более широкий запрос.
- **Google, временной фильтр:** `"bridge" after:2025-05-01 before:2025-06-01`. Ограничивает результаты по дате, которую понимает поисковик, а не доказывает время события.
- **Bing, альтернативы:** `"north crossing" OR "northern bridge"`. `OR` и `NOT` в Bing пишутся заглавными. Проверяйте сложные группировки небольшими отдельными запросами.
- **Bing, язык:** `bridge language:en`. Для полноценного многоязычного исследования составьте отдельные запросы на языке источника, а не только включайте фильтр.

Домены `example.org` в примерах — учебные; эти запросы не обещают реальные находки. Для своей задачи заменяйте их разрешённым целевым источником. Не включайте чувствительные данные в поисковые запросы и запросы к ИИ.

## Последовательность из пяти шагов

1. Определите сущность, действие, место и период: «переправа — допуск автомобилей — учебный город — май 2025».
2. Запишите синонимы и переводы: `открытие / opening`, `испытания / load testing`, `пешеходный / pedestrian`.
3. Выполните широкий запрос, затем один фильтр за раз. Слишком узкий запрос создаёт ложное отсутствие.
4. Откройте первичный документ. Сниппет может быть устаревшим, обрезанным или относиться к другому фрагменту.
5. Сохраните находку и отрицательный результат с границами проверки. «Не нашёл» не означает «не существует».

## Архивы и бесплатная альтернатива

Для публичных страниц проверьте [Wayback Machine](https://web.archive.org/). Снимок показывает сохранённую версию страницы; динамические элементы могли не попасть в архив. Дата снимка не равна дате публикации и события. Отсутствие снимка не доказывает отсутствия страницы.

Если сервис недоступен, используйте [локальные версии страницы](../assets/case/README.md) и [корпус фрагментов](../assets/case/search-corpus.json). Он предназначен для проектирования запроса и оценки релевантности, не имитирует алгоритм поисковика. `cache:` не включён как надёжный обязательный инструмент.
