# Измерение без вымышленных метрик

В исходной версии проекта не включены сторонние счётчики посещений. GitHub Pages сам по себе не даёт автору встроенную подробную аналитику просмотров сайта. Поэтому репозиторий, сайт и площадки запуска нужно измерять отдельно.

## Что доступно бесплатно

- **GitHub Stars:** публичное текущее число — через страницу репозитория или `gh api repos/bioxhaust/evidence-first-osint --jq .stargazers_count`. Разность двух снимков — чистое изменение, а не количество всех людей, когда-либо добавивших звезду. Удаления звёзд могут уменьшить число.
- **GitHub Traffic:** владельцу доступны просмотры, уникальные посетители, клоны и некоторые источники переходов в Insights → Traffic. API и интерфейс используют ограниченное окно; для views/clones GitHub документирует последние 14 дней. Сохраняйте снимки хотя бы еженедельно. Не публикуйте необработанные сведения о посетителях.
- **Вклад:** вручную классифицируйте реальные Issues и PR: ошибка, улучшение урока, перевод, новое упражнение. Число открытых Issues не равно качеству участия; полезнее время до первого содержательного ответа и количество принятых исправлений.
- **Площадки:** сохраняйте доступные автору показы, просмотры и клики только если интерфейс действительно их сообщает. Просмотры Telegram-поста и показы LinkedIn не равны переходам на сайт. Если клики не доступны, запишите «не измерялось».

Официальная документация: [Repository traffic](https://docs.github.com/en/rest/metrics/traffic), [Viewing traffic](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-traffic-to-a-repository), [Stargazers](https://docs.github.com/en/rest/activity/starring). Это справочные ссылки; конкретная доступность полей и прав проверяется в используемом аккаунте.

## Снимок раз в неделю

```sh
gh api repos/bioxhaust/evidence-first-osint --jq '{stars: .stargazers_count, forks: .forks_count, open_issues_and_prs: .open_issues_count}'
gh api repos/bioxhaust/evidence-first-osint/traffic/views
gh api repos/bioxhaust/evidence-first-osint/traffic/clones
gh api repos/bioxhaust/evidence-first-osint/traffic/popular/referrers
```

Команды чтения требуют подходящей авторизации. `open_issues_count` включает pull requests; не называйте это число только багами. Ответ 403 или отсутствие данных означает недостаток прав/данных, не нулевой трафик. Запишите фактическую дату с поясом, окно метрики, источник и путь к сохранённому ответу. Сырые снимки собственного аккаунта лучше хранить локально, публиковать — агрегированные результаты при необходимости.

[CSV-шаблон](metrics-template.csv) содержит только заголовок: данные должны появиться после реального измерения. `value` оставляйте пустым для отсутствующих данных и объясняйте это в `notes`; не заменяйте пустоту нулём. Для окна 14 дней соседние недельные снимки перекрываются: **не складывайте их итоги**, иначе посчитаете дни дважды. Суммировать можно ежедневные строки после удаления дублей по дате и типу метрики.

## Переходы на сайт

Параметры вроде `?utm_source=telegram&utm_medium=post&utm_campaign=v1` лишь помечают URL. Без установленной аналитики они не создают отчёт о переходах. Не утверждайте, что наличие UTM означает измеренные клики.

Если позднее нужна статистика сайта, владелец может выбрать подходящий бесплатный или самостоятельно размещаемый счётчик, оценив актуальные лимиты, обработку данных, юрисдикцию и необходимость уведомления/согласия. Не добавляйте трекинг скрытно. До этого честный показатель — «посещаемость Pages не измерялась». Доступные счётчики кликов площадки относятся только к её переходам и могут учитывать автоматические запросы.

## Как интерпретировать

Зафиксируйте время каждого размещения, площадку, ссылку на конкретный материал и доступные результаты. Рост звёзд в тот же день сам по себе не доказывает причинную связь с постом. Нельзя делить прирост звёзд на показы одной площадки и называть это общей конверсией посетителя: аудитории, периоды и единицы разные.

Полезный месячный итог: «проверены 4 сообщения об ошибках, исправлены 3 инструкции, получен один принятый перевод» — только при реальных событиях. Пока их нет, эти числа не подставляются. Не используйте ботов, обмен звёздами, фиктивные отзывы, платные накрутки или массовые однотипные PR.
