## Принцип запуска

Покажите конкретный результат: самоссылку профиля, ложный плюс Sherlock или короткое задание тренажёра. Полный обязательный путь требует установки инструмента; не называйте его целиком маршрутом без установки. Укажите свою связь с проектом и язык уроков. Не просите голосовать, не пишите незнакомым людям массово и не повторяйте один текст по множеству каналов. Количество звёзд и посещений пока не измерено; обещания роста отсутствуют.

## Проверка правил

Дата проверки — **3 ноября 2026 года**. [Результаты HTTP и короткие выдержки](policy-review-2026-11-03.json) отличают доступные правила от заблокированных запросов. У r/OSINT локальные правила не удалось прочитать из-за HTTP 403. Это означает «не проверено», а не разрешение на саморекламу. HN запрещает сгенерированный текст в публикациях, поэтому готовый AI-анонс для HN здесь намеренно не предлагается. Хабр требует учитывать ограничения рекламы и самопиара; публичный анонс туда не подготовлен как автоматически допустимый.

Перед отправкой автору следует прочитать текст, подтвердить факты и актуальные правила выбранного места. Это редакторские черновики, подготовленные с помощью ИИ; не приписывайте им личный опыт, которого у вас не было.

Выпуск использует локальный прогресс в браузере. Подключение GitHub OAuth и облачной синхронизации отложено до завершения настройки провайдера; адаптер и миграция включены, облачный интерфейс отключён, живой вход не проверен. Это текущий этап развёртывания, не постоянный отказ от синхронизации.
