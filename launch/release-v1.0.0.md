# Evidence First OSINT v1.0.0

A complete free Russian OSINT course, from a research question to a reproducible report.

- 18 modules and 18 labs, including optional Python/API foundations.
- Three intermediate projects and one synthetic capstone, with separate worked solutions and rubrics.
- Original labelled training records, maps, JPEG illustrations, six-second MP4 and SHA-256 manifest.
- English overview/course map plus bilingual quickstart, core cheatsheets and reporting templates. Full lessons remain Russian.
- Searchable MkDocs Material website, responsive navigation and light/dark themes.

Start: https://bioxhaust.github.io/evidence-first-osint/resources/quickstart/  
English quickstart: https://bioxhaust.github.io/evidence-first-osint/resources/quickstart.en/

Validation: 11 Python tests, 25 fixture hashes, strict site build, 95 HTML pages and more than 8,000 internal-link checks. Browser checks covered search in both languages, lesson navigation, the challenge and emulated mobile widths. External link checks are dated and distinguish HTTP reachability from service functionality.

Known limits: one synthetic case, no learner pilot or independent expert certification, incomplete English translation, no Windows or screen-reader testing. EUR-Lex returned empty HTTP 202 in the test environment. Details: https://bioxhaust.github.io/evidence-first-osint/about/quality/

Original content/training assets: CC BY 4.0. Original code: MIT. All required practice is local and free; no paid accounts or API keys are required.
